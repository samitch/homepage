For C++ aficionados
Boost Graph Library (BGL)
CGAL interfaces to it / uses it.
www.boost.org, search for "graph library" internally
complicated, templated, generic, flexible - some love it...

C++ STL standard template library

Cubit, Sandia's mesh generation toolkit,
http://cubit.sandia.gov/
Request the educational version; it's free, but no source code is available
unless you form a research partnership with them.
